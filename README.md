# PICO-8 SHUMP

## Projectile System

The projectile system has two jobs:

- Generate projectiles for the player ship when a fire button is pressed.
- Generate projectiles for the enemies when they fire at the player ship.

Both jobs create a base projectile, which is just a series of sprites, a hit-box and an animation function to handle its animation.

Adding the remaining properties to the projectile works differently depending on if it was created by the player or an enemy.

----

## Base Projectile

Adding a new base projectile requires creating both a new projectile definition, following the below pattern, and adding a string literal to the projectile string literals before the projectile types are declared in `Projectiles.lua`, the projectile definitions are also stored here, in the `pTypes` table which comes right after the string literals.

### **Projectile String Literals**

The string literals are declared before the projectile definition, there are simple a string definition.

```` lua
yellowBullet = "yellowBullet"
yellowBlaster = "yellowBlaster"
pinkBullet = "pinkBullet"
````

Then when creating a new projectile definition use the same string variable for the row name.

### **Projectile Definition Pattern**

A table containing the properties needed to generate a projectile, each entry requires the following properties.

- `key`: The name of the projectile, **MUST** match the string-literal of the projectile.
- `ani`: Table of projectile animation properties.
  - `ani.start`: The number of the first sprite of the animation.
  - `ani.fin`: The number of the end sprite of the animation.
  - `ani.delay`: The delay in frames before changing to the next sprite in the animation.
- `hitBox`: A table containing properties of the hit-box.
  - `hitBox.w`: The width of the hit-box.
  - `hitBox.h`: The height of the hit-box.
  - `hitBox.offX`: The **X**-axis offset of the hit-box.
  - `hitBox.offY`: The **Y**-axis offset of the hit-box.
- `animate`: A **function** which covers how to animate the sprites of the animation.

## Player Projectiles

For projectiles generated by the player a weapon definition is required in addition to a projectile definition.

### **Weapon Definition Pattern**

A table containing the properties needed to fire a weapon.

- `pCfg`: The config of the projectile type the weapon uses.
- `spd`: The speed of the projectiles.
- `dam`: The damage each projectile does.
- `rof`: The delay before player can fire the weapon again.
- `sfx`:  The sound effect to play when the weapon fires.
- `fireFunc`: The firing function the weapon uses.

In addition some weapon types fire more than one projectile, for these there some additional properties.

- `num`: The number of projectiles to fire.
- `ang`: The angle the projectiles leave the ships (0.5) is upwards.

### **Fire Function Pattern**

Gets the required data needed by the projectile system to generate the shot type used by the weapon and then pass it into the projectile system.

#### **Input Parameters**

- `x`: The starting **X** axis.
- `y`: The starting **Y** axis.
- `wepCfg`:  The config for the weapon being fired.

## **Firing a projectile**

- Get the config for the projectile used by the weapon.
- Call the fire function to generate projectiles, passing in the data from both the weapon and projectile configs to generate the needed projectiles.
- Play the sound effect from the weapon config.
